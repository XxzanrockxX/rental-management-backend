# Rental Management - Backend

REST API for a vehicle rental management system focused on customer and rental contract management.

## Technologies

- Node.js
- Express
- MongoDB Atlas
- Mongoose
- JSON Web Tokens (JWT)
- Open-Meteo API

## Planned Features

- User authentication using JWT.
- Year and period management.
- Rental contract management.
- Customer registration and management.
- Contract search by date, customer name, ID number, and rented vehicle.
- Integration with the Open-Meteo weather API.
